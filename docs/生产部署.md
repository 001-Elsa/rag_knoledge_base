# 生产部署指南：从云服务器到线上 Demo

本文给出单机 Docker Compose 部署流程。实际耗时和成本取决于云厂商、实例规格与模型调用量。

## 一、买服务器

- 阿里云/腾讯云轻量应用服务器即可，**2 核 4G** 起步（bge 模型 + 四个容器需要内存），
  系统选 Ubuntu 22.04；新用户优惠通常每月 30-60 元；
- 安全组/防火墙放行端口：**80、443**（对外只开这两个；5432/6379/8000 一律不对公网开放）。

## 二、装 Docker

```bash
# 国内服务器建议用阿里云镜像脚本
curl -fsSL https://get.docker.com | bash -s docker --mirror Aliyun
systemctl enable --now docker
```

## 三、部署项目

```bash
# 上传项目（本机执行）
scp rag-knowledge-base.zip root@服务器IP:/opt/ && ssh root@服务器IP
cd /opt && unzip rag-knowledge-base.zip && cd rag-knowledge-base

# 配置
cp .env.example .env
vim .env
#   LLM_API_KEY=sk-xxx            ← 必填
#   JWT_SECRET=<openssl rand -hex 32 生成的随机串>   ← 生产必须换
#   DOMAIN=demo.你的域名.com       ← 有域名填这个，Caddy 自动办 HTTPS

# 启动（api/worker/postgres/redis/flower + Caddy 反代）
docker compose --profile edge up -d --build

# 想带监控大盘一起
docker compose --profile edge --profile monitoring up -d --build
```

## 四、域名与 HTTPS

1. 域名解析：加一条 A 记录指向服务器 IP（如 demo.example.com）；
2. `.env` 里 `DOMAIN=demo.example.com`，重启 caddy：`docker compose --profile edge up -d caddy`；
3. Caddy 自动向 Let's Encrypt 申请证书并续期，**零配置 HTTPS**。
   没有域名也能用：不设 DOMAIN 时 Caddy 走 80 端口纯 HTTP，`http://服务器IP` 直接访问。

> 备案提醒：使用中国大陆服务器 + 域名需要 ICP 备案（约 1-2 周）；
> 不想备案可以选香港/新加坡区域的服务器，或者先用 IP 直接访问。

## 五、上线检查清单

- [ ] `JWT_SECRET` 已换成长随机串（不是 dev-secret-change-me）
- [ ] 数据库/Redis 端口未对公网开放（安全组只开 80/443）
- [ ] `docker compose logs api` 无报错，`/api/health` 返回 ok
- [ ] 注册一个演示账号并上传不含敏感信息的示例文档
- [ ] Flower(5555)/Grafana(3000) 端口不对公网开放，需要看时用 SSH 隧道：
      `ssh -L 3000:localhost:3000 root@服务器IP`
- [ ] 给 DeepSeek 账户设置用量上限（防止 demo 被刷爆产生费用）
- [ ] 顺手把 RATE_LIMIT_CHAT 调低（如 5/minute），公开 demo 防滥用

## 六、日常运维

```bash
docker compose ps                  # 状态
docker compose logs -f api         # 日志（带请求 ID，可 grep rid=xxx 追踪单个请求）
docker compose pull && docker compose --profile edge up -d   # 更新
docker exec -t <postgres容器> pg_dump -U rag ragdb > backup.sql   # 备份
```
